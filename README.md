# City University of Macau $\LaTeX$ Templates

A collection of  $\LaTeX$ templates for coursework, presentations, and theses at City University of Macau. Each template is self-contained and includes a sample PDF for previewing the layout before editing.

##  Structure

```text
-
|-- Assignment/
|   |-- Type 1/          # Chinese coursework template
|   |-- Type 2/          # English coursework template
|   |-- Type 3/          # IEEE-style report template
|-- Presentation/
|   |-- Type 1/
|   |-- Type 2/
|   |-- Type 3/          # Three Beamer slide themes
|-- Thesis/
|   |-- Chinese/
|   |-- English/         # Modular thesis templates with Sections/, figures, references, and declaration support
|-- figures/
|-- LICENSE
-
```

## Quick Start

1. Choose a template folder.
2. Edit the relevant files:
   - Content: edit the  `.tex` file, usually `main.tex`.
   - Styles: edit the `.sty` file if the selected template provides one.
   - References: add or update entries in the `.bib` file.
3. Compile the selected project locally or upload its folder to Overleaf.

The thesis template is also available on [Overleaf](https://www.overleaf.com/latex/templates/city-university-of-macau-thesis-template/qtbkhjdwbxkh) and can be used directly online.
